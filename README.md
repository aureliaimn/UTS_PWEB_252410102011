Teras Kopi adalah website pencatatan stok untuk sebuah kedai kopi. Website ini
membantu mencatat stok bahan baku, perasa, kemasan, dan peralatan, serta
menandai barang mana yang sudah di bawah batas minimum dan perlu dibeli lagi.

## Halaman
- **Login:** masuk dengan username, lalu username dikirim ke halaman lain lewat request parameter.
- **Dashboard:** ringkasan jumlah barang, jumlah yang perlu restok, dan kategori.
- **Profil:** biodata dan username yang sedang login.
- **Pengelolaan stok:** tabel seluruh barang beserta status stoknya.
